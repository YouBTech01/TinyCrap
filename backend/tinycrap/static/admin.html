API documentation

Base URL: . Send your key in the X-API-Key header. Every response is JSON with "ok": true|false. Only 2 downloads run at once; the rest wait in line and start automatically (queue_position tells you where you are).

POST /api/analyze{"url": "…"} → title, thumbnail, video qualities, audio formats
POST /api/download/video{"url","quality":"1080|best","container":"mp4|webm"} → job
POST /api/download/audio{"url","format":"best|mp3|m4a|opus|wav|flac","bitrate":192} → job
GET /api/progress/<job_id>stage, percent, queue_position (0 = running), result.download_url when ready
GET /api/download/<job_id>the file (supports Range); kept for ~30 minutes
POST /api/cancel/<job_id>stop a download or leave the line
GET /api/healthserver health, no key needed
GET /api/update?code=Nthe newest update if N is older, else null; no key needed

Errors: 401 wrong key · 422 link not supported / private · 429 rate limit or too many downloads for one client · 503 server tools missing.
